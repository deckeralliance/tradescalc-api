Ship in Minutes, Not Weeks

Simple REST endpoints. Predictable JSON responses. One API key and you're calculating.

REQUEST 
# Calculate voltage drop for a 120V circuit
curl -X POST \
  https://tradescalc.p.rapidapi.com/electrical/voltage-drop \
  -H "X-RapidAPI-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "voltage": 120,
    "current": 20,
    "length_ft": 150,
    "wire_size": "12",
    "conduit_type": "EMT",
    "phase": "single"
  }'
RESPONSE · 47ms

  "voltage_drop_volts": 5.76,
  "voltage_drop_percent": 4.8,

  "nec_compliant": false,
